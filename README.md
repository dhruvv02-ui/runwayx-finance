# ⚡ RunwayX | Autonomous Settlement & Reconciliation Engine
*Built for Razorpay Buildathon*

## 🚀 Overview
**RunwayX** is an autonomous AI-powered financial controller designed specifically to solve complex payment reconciliation and merchant settlement friction. Modern businesses process thousands of transactions daily across multiple payment gateways and bank accounts, leading to payout mismatches, unverified MDR/GST fee deductions, and tedious manual audits. RunwayX automates this entire lifecycle end-to-end.

---

## 🛠️ Key Hackathon Features
* **Deterministic Multi-Source Matching Engine:** Instantly cross-verifies internal ledger orders against raw bank statement payouts with high AI confidence scoring.
* **Algorithmic MDR & GST Tax Variance Auditing:** Automatically computes and flags hidden fee deductions, merchant discount rates (MDR), and tax discrepancies.
* **1-Click Autonomous Dispute Dispatch:** Generates and dispatches formal escalation notices straight to gateway desks for missing or failed settlements.
* **Certified Statutory Compliance Pack:** Generates professional, multi-sheet audit-ready Excel packages (`.xlsx`) with automated styling, metrics, and structured logs.
* **Production-Grade Architecture:** Features a sleek, responsive dual-theme (Dark/Light) UI built with Streamlit and Plotly, complete with custom branding, an animated splash loading screen, and secure Razorpay infrastructure integration.

---

## 📦 Libraries & Tech Stack
RunwayX is built using the following core Python libraries and frameworks:

* **[Streamlit](https://streamlit.io/)** (v1.30+) – For building the high-performance, interactive front-end web dashboard.
* **[Pandas](https://pandas.pydata.org/)** (v2.0+) – For high-speed tabular data processing, merging, and financial calculations.
* **[Plotly](https://plotly.com/python/)** (v5.0+) – For dynamic, responsive financial visualizations and analytics charts.
* **[Openpyxl](https://openpyxl.readthedocs.io/)** – For generating styled, multi-sheet Excel compliance audit packages (`.xlsx`).
